# Skill-强驱动：无障碍色彩与视觉包容性检查系统

本系统是一个企业级的无障碍色彩自动化检查工具。针对 UI 设计图或在线网页（URL），提供从宏观全景到微观网格的深度计算机视觉（CV）扫描，自动排查色盲盲区、对比度合规性，并生成极具美学与交互体验的 HTML 诊断分析报告。

## 核心突破特性

* ** 100×100 像素网格微观扫描**：内置长网页防爆机制与极速降维算法。像显微镜一样扫过全图，自动捕获局部（如按钮、标签内）的对比度风险切片。
* ** 视障边缘消融预警 (CVD Melt Detection)**：不仅提供常规色盲滤镜，更引入 CIEDE2000 色差公式。自动揪出正常人看着清晰，但在色盲眼中色差 ΔE 暴跌至 3.0 以下、导致组件“隐形”的高危边界，并在原图上绘制靶心连线。
* ** WCAG 2.1 & APCA 双轨引擎**：不仅支持传统的 4.5:1 对比度标准，更全量引入 WCAG 3.0 的下一代 **APCA (Lc) 视网膜知觉亮度算法**，彻底解决深色模式下传统算法失效的痛点。
* ** 智能修复工单系统**：发现错误不是终点，解决才是。系统自带 HSL 二分法微调降级，并首选匹配权威的 **Okabe-Ito 色盲安全色板**，直接给出前端可用的修复后色值。
* ** 极客级 HTML 报告大盘**：纯原生生成，无需外部网络依赖。内置全屏 Lightbox 丝滑放大交互、自动异常模块折叠，且原生适配 `Ctrl+P` 打印强制全展开输出，适合直接作为审计底稿存档。
